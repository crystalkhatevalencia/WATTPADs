# StoryVerse — ITE 1 Storybook-Like Wattpad Project

## Open the website
1. Extract `StoryVerse_ITE1_Project.zip`.
2. Open the extracted folder.
3. Open `index.html` in a browser. No server or installation is required for local browsing.

## Files
- `index.html` — home page, navigation, searchable/filterable story library.
- `story.html` — shared story-reading page; each Read Story link opens the selected story using its ID.
- `style.css` — one external stylesheet for all pages, responsive layout, dark/light theme.
- `script.js` — external JavaScript for search, genre filters, sorting, likes, dark/light mode, synopsis toggle, copy link, and reading progress.
- `stories.js` — story data for 30 original stories, each with exactly one chapter.
- `images/` — 30 original SVG cover images and 30 matching supporting scene illustrations.

## Included JavaScript features
1. Dark/light mode (saved in local storage).
2. Search and genre filtering, plus sorting.
3. Like buttons (saved in local storage).
4. Show/hide synopsis.
5. Book details and reading page.
6. Reading progress indicator.
7. Copy story link.

## Notes
- All stories and artwork in this project are original sample content created for this student project.
- The image assets are SVG files so they remain sharp and are not stretched. Browsers display SVG image files directly; the files are stored in the required `images` folder.
- Google Fonts are an optional online enhancement; the page uses fallback fonts if offline.
